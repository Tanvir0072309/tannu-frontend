# Tannu Frontend

Tannu Frontend is a lightweight, high-performance single-page application (SPA) engineered with React and Vite. This repository encompasses the core client-side architecture, UI components, and asset configurations for the Tannu ecosystem.

---

## Key Features

* **Vite-Driven Development:** Leverages Vite for instant Hot Module Replacement (HMR) and optimized cold server starts.
* **Component-Driven Design:** Built around an isolated, modular React component architecture ensuring scalable UI development.
* **Production-Ready Bundling:** Pre-configured Rollup compilation pipeline for asset optimization and efficient code-splitting.

---

## Technical Stack

* **Core Library:** React 18+
* **Build Tooling:** Vite
* **Language Specification:** JavaScript (ECMAScript 6+)
* **Styling Paradigm:** Standard CSS3 / Component-level isolated styling

---

## Prerequisites

Before starting execution, ensure your local development environment meets the following specifications:
* **Node.js:** Runtime version 16.x or greater (LTS recommended)
* **Package Manager:** npm (v7+), yarn, or pnpm
